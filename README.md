# حال خوب | Haal Khoob 🌿

وب‌اپلیکیشن دو‌زبانه فارسی/انگلیسی برای آرامش، خودشناسی، روان‌شناسی عمومی و الهام روزانه؛ با طراحی کرم و سبز زیتونی، راست‌چین فارسی، واکنش‌گرا و قابل نصب به‌صورت PWA.

## امکانات
- زبان فارسی و انگلیسی با تغییر فوری جهت صفحه (RTL/LTR)
- جمله روزانه و کتابخانه قابل جست‌وجو و دسته‌بندی، همراه منبع
- تفکیک روشن برداشت آزاد از نقل‌قول مستقیم؛ از ساختن نقل‌قول جعلی پرهیز شده است
- نگاه‌های ایرانی و جهانی از جمله آثار و سخنرانی‌های دکتر حسین الهی قمشه‌ای
- فیلم‌های ایرانی و خارجی با توضیح موضوع و لینک اطلاعات فیلم
- تازه‌ترین آثار پژوهشی روان‌شناسی از Crossref هنگام بازشدن برنامه؛ مسیر جایگزین APA و PubMed
- ذخیره جمله‌های موردعلاقه و یادداشت شخصی در مرورگر دستگاه
- تمرین تنفس و پشتیبانی آفلاین پوسته اصلی
- آیکن ۲۵۶ پیکسلی ساخته‌شده از همان تصویر ارسالی صاحب پروژه، بدون نماد اضافه

## منابع
APA، WHO، PubMed، Crossref، Greater Good Science Center (UC Berkeley)، Positive Psychology Center (University of Pennsylvania)، Kristin Neff و وب‌سایت/کانال رسمی دکتر الهی قمشه‌ای.

## انتشار
گردش‌کار `.github/workflows/pages.yml` با هر Commit روی `main`، GitHub Pages را فعال/پیکربندی و وب‌اپ را منتشر می‌کند.

آدرس پروژه پس از موفقیت انتشار:
`https://alimokhtari3916-eng.github.io/haal-khoob/`

در Android: سایت را با Chrome باز کن و Install app یا Add to Home screen را بزن.
در iPhone: سایت را با Safari باز کن، Share و سپس Add to Home Screen را انتخاب کن.

## به‌روزرسانی
جمله‌ها و فیلم‌های منتخب با Commitهای جدید به‌روزرسانی می‌شوند. بخش پژوهش‌ها با هر بار بازشدن و با دکمه Refresh از API عمومی Crossref محتوای تازه دریافت می‌کند؛ این بخش به اینترنت نیاز دارد.

## یادآوری سلامت
محتوا برای آموزش و تأمل عمومی است و تشخیص، درمان یا توصیه پزشکی نیست. در رنج شدید یا مداوم از متخصص واجد صلاحیت کمک بگیر.
