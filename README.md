# حال خوب | Haal Khoob 🌿

یک وب‌اپلیکیشن فارسی/انگلیسی درباره آرامش، خودشناسی و روان‌شناسی عمومی؛ راست‌چین، واکنش‌گرا و قابل نصب به‌صورت PWA.

## امکانات نسخه فعلی
- تجربه فارسی و انگلیسی و چیدمان RTL/LTR
- پوسته‌های آرام، شاد، تیره، خلوت/تأملی و گرم
- حال‌سنجی روزانه؛ وضعیت فقط در مرورگر دستگاه ذخیره می‌شود
- مسیر رشد ۷ و ۲۱ روزه با ثبت پیشرفت محلی
- جمله‌های الهام‌بخش از منابع ایرانی و بین‌المللی؛ تفکیک نقل‌قول مستقیم و برداشت آزاد
- فیلم‌های ایرانی و خارجی
- اتاق صدا: باران ریز، باران پنجره، باران سقف، طوفان و رعد، موج دریا، جنگل و پرنده، شومینه و موسیقی مینیمال. این صداها در مرورگر ساخته می‌شوند؛ فایل موسیقی دارای حق نشر در مخزن کپی نشده است.
- خلاصه‌های مستقل و کوتاه کتاب‌های روان‌شناسی، با لینک ناشر
- پادکست‌های رسمی با لینک شنیدن/متن
- پژوهش‌های تازه از Crossref و مسیرهای جایگزین APA/PubMed
- دفترچه شخصی، ذخیره جمله‌ها و تمرین تنفس
- یار حال خوب: در حالت پیش‌فرض راهنمای محلی و ازپیش‌تعریف‌شده؛ اتصال اختیاری به مدل زبانی از مسیر امن Worker
- پوسته آیکن از تصویر اصلی صاحب پروژه

## اجرا
این پروژه استاتیک است و به نصب بسته نیاز ندارد. وب‌سایت با GitHub Pages منتشر می‌شود:
https://alimokhtari3916-eng.github.io/haal-khoob/

در Android: لینک را با Chrome باز کن و Install app یا Add to Home screen را بزن.
در iPhone: لینک را با Safari باز کن، Share و سپس Add to Home Screen را انتخاب کن.

این خروجی PWA است، نه فایل APK؛ نصب آن از مرورگر و افزودن به صفحه اصلی انجام می‌شود.

## به‌روزرسانی و محتوا
- پژوهش‌ها هنگام بازشدن برنامه و با دکمه Refresh از Crossref دریافت می‌شوند.
- گزارش محتوای هفتگی در ChatGPT برای انتخاب منابع تازه تنظیم شده است؛ این گزارش بدون تأیید صاحب پروژه چیزی را در GitHub تغییر نمی‌دهد.
- فیلم‌ها، خلاصه کتاب‌ها و جمله‌های منتخب با Commitهای جدید توسعه می‌یابند.
- صداهای محیطی به‌صورت الگوریتمی در مرورگر تولید می‌شوند؛ لینک منابع صوتی خارجی صرفاً برای دریافت جداگانه است و باید مجوز هر فایل بررسی شود.

## دستیار هوش مصنوعی واقعی (اختیاری)
GitHub Pages بک‌اند ندارد. برای فعال‌کردن مدل آنلاین باید Worker سمت سرور را طبق `AI_SETUP.md` منتشر کرد و کلید API را فقط به‌صورت Secret در سرویس میزبان ثبت کرد. هرگز کلید را در فایل‌های مرورگر یا مخزن عمومی قرار ندهید.

## منابع منتخب
APA، WHO، PubMed، Crossref، Greater Good Science Center (UC Berkeley)، Positive Psychology Center (University of Pennsylvania)، Kristin Neff، Mixkit و منابع رسمی آثار/پادکست‌ها.

## سلامت و حریم خصوصی
این برنامه ابزار آموزش و تأمل عمومی است، نه تشخیص یا درمان. اگر رنج شدید یا مداوم است یا خطر فوری وجود دارد، از متخصص یا خدمات اضطراری محل زندگی کمک بگیر. یادداشت و حال‌سنجی در مرورگر همین دستگاه نگهداری می‌شوند؛ اگر دستیار ابری فعال شود، متن گفتگو برای تولید پاسخ به سرویس مدل فرستاده خواهد شد.

## دانلود و نصب فایل اندروید (APK)

هر بار که کد برنامه در شاخه `main` تغییر کند، GitHub Actions یک APK اندروید و یک فایل ZIP آماده انتقال به موبایل می‌سازد.

- ZIP شامل فایل `haal-khoob.apk` و راهنمای نصب است:
  https://github.com/alimokhtari3916-eng/haal-khoob/releases/latest/download/haal-khoob-android-install.zip
- دانلود مستقیم APK:
  https://github.com/alimokhtari3916-eng/haal-khoob/releases/latest/download/haal-khoob.apk

روش نصب:
1. ZIP را دانلود و Extract کنید.
2. فایل `haal-khoob.apk` را به گوشی اندروید منتقل کنید.
3. APK را باز و Install را انتخاب کنید. در صورت درخواست اندروید، اجازه نصب از همان منبع را فعال کنید.

این ساخت فعلی یک APK آزمایشیِ امضاشده با کلید Debug است. برای نصب نسخه‌های بعدی ممکن است لازم باشد نسخه قبلی حذف شود؛ برای انتشار پایدار و به‌روزرسانی بدون حذف، باید keystore اختصاصی و خصوصی در Secrets گیت‌هاب تنظیم شود.
